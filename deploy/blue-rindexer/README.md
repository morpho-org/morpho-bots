# blue-rindexer

The discovery indexer behind `@repo/blue-liquidation`: a no-code [rindexer](https://rindexer.xyz)
project that indexes the Morpho Blue `Borrow` event for every configured network (Base 8453,
Robinhood 4663) into one Postgres table, `blue_liquidation_morpho.borrow`, discriminated by
rindexer's `network` column. Each blue tick reads the distinct `(market id, borrower)` universe from
that table (`DATABASE_URL`), then re-checks every candidate fresh on-chain — the index is a coverage
source, never the source of truth.

Not a bun workspace: this directory is a deploy artifact (`rindexer.yaml` + `Dockerfile`), not a
TypeScript package. The Morpho ABI it needs is generated by `@repo/contracts` at image build time
and baked in, so it is never committed.

- Networks read RPCs from `RINDEXER_RPC_URL_<chainId>` (see `rindexer.yaml` interpolations).
- Local: `docker compose -f deploy/docker-compose.blue.yml up postgres rindexer` from the repo root.
- Prod (Railway): the `rindexer` service builds this Dockerfile
  (`RAILWAY_DOCKERFILE_PATH=deploy/blue-rindexer/Dockerfile`) — provisioned by
  `deploy/scripts/deploy-railway-blue.ts`.
- To add a chain: extend `rindexer.yaml`, the blue chain map (`packages/blue-liquidation/src/config.ts`),
  and the deploy script's `CHAINS` list together.
