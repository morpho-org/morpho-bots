# Retrospectives

Project- and initiative-level retrospectives for `morpho-bots`. One file per retro.

## Naming

`YYYY-MM-<project-slug>.md` — for example, `2026-04-bootstrap-curator-bots.md`.

## Adding a Retro

A retro template will be added with the first retro. Until then, anchor new retros on the
project's Linear summary, key PRs, and the goals stated in the originating TIB.

See [`../GUIDANCE.md`](../GUIDANCE.md) for when a retro is appropriate and how it relates to TIBs
and Linear projects.
